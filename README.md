# Infinito Barbearia

Site da Infinito Barbearia, na Av. Prof. Papini, 76 (Interlagos, SP).

https://joaomvsa.github.io/barbearia_infinito/

Página única com galeria de cortes, agendamento pelo Cal.com, avaliações do Google, preços e localização.

Feito em HTML, CSS e JS, sem framework nem build. Roda no GitHub Pages.

## Rodar local

```
python3 -m http.server 8080
```

## Organização

```
index.html
css/style.css
js/main.js         galeria, lightbox, menu e embed do Cal.com
img/               imagens do site (.webp)
fotos-originais/   fotos originais em .jpeg
```

As fotos da galeria e os eventos do Cal.com ficam em listas no começo do `js/main.js`.
